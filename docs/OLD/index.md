# HomingCast

HomingCast is a module that allows you to create dynamic, real-time simulated homing projectiles without relying on Roblox physics

For example, it can be used for missiles, spells, or homing bullets

Download: [HomingCast](https://create.roblox.com/store/asset/80411622110702/Homing-Cast)

It is similar to [FastCast](https://devforum.roblox.com/t/making-a-combat-game-with-ranged-weapons-fastcast-may-be-the-module-for-you/133474), which is designed to simulate projectile drop physics. However, HomingCast focuses on creating homing projectiles without using Roblox physics

!!! warning "Recommendation"
    FastCast is not recommended for new projects

    A more modern alternative is [SwiftCast](https://devforum.roblox.com/t/swiftcast-simple-fast-and-easy-projectiles/4477145).
