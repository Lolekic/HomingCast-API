# Raycast function

In order to use the raycast function, access it as `HomingCast.RaycastFunctions.YOUR_RAYCAST_FUNCTION` and put it inside of parameters under `RaycastFunction` key

There are currently 4 types of raycast functions present

---
## Raycast (Default)

Uses [Raycast](https://create.roblox.com/docs/workspace/raycasting) to detect the hits

---
## BlockCast

Uses [Blockcast](https://create.roblox.com/docs/reference/engine/classes/WorldRoot#Blockcast) to detect the hits

---
## Spherecast

Uses [Spherecast](https://create.roblox.com/docs/reference/engine/classes/WorldRoot#Spherecast) to detect the hits

---
## Shapecast

Uses [Shapecast](https://create.roblox.com/docs/reference/engine/classes/WorldRoot#Shapecast) to detect the hits
