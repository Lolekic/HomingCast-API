# States

There are states inside of projectile raw table

Each state is marked with

- `r` for direct read permission
- `w` for direct write permission

## States

---
### Position [rw] (number)

Current projectile's position

---
### Velocity [rw] (number)

Current projectile's velocity

---
### Elapsed [r] (number)

How much time elapsed after the projectile was created

---
### DistanceTravelled [r] (number)

How much distance the projectile travelled after it was created
